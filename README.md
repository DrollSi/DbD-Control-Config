\# DbD Control Config



Программа для настройки управления в Dead by Daylight: 

меняет привязки клавиш и силу нажатий напрямую в файле сохранения игры.



\## Как пользоваться

1\. Скачайте последний релиз со страницы Releases

2\. Запустите DbD Control Config.exe

3\. Укажите путь к папке с игрой и подтвердите согласие



\## Сборка из исходников

python -m PyInstaller --onefile --windowed --name "DbD Control Config" --icon "ico.ico" "DbD Control Config.py"



⚠️ Программа изменяет файлы сохранения игры.

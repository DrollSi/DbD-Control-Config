# DbD Control Config

Программа для настройки управления в Dead by Daylight: меняет привязки клавиш и силу нажатий напрямую в файле сохранения игры.

> ⚠️ **Важно:** программа изменяет файлы сохранения игры. Используйте на свой риск.

- Отдельные настройки для **Убийцы**, **Выжившего** и **режима зрителя**.

## 🖥️ Совместимость и известные нюансы

- **ОС:** Windows 10 и 11.
- **Антивирус:** Windows SmartScreen может показывать предупреждение «Неизвестный издатель» — это нормально для неподписанных exe-файлов.
- **Текущие ограничения (будут исправлены в следующих версиях):**
  - На Windows 10 воспроизведение встроенного видео-туториала может не работать.
  - На Windows 10 возможны проблемы с отображением элементов дизайна.
  - В текущей версии нет поддержки биндов для геймпада (планируется).

## 🚀 Как установить и запустить

1. Скачайте архив из раздела [Releases](https://github.com/DrollSi/DbD-Control-Config/releases).
2. Распакуйте содержимое.
3. Запустите `DbD Control Config.exe`.
